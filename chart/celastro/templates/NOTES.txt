{{- if gt (int .Values.replicas) 1 }}
celastro is starting as {{ .Values.replicas }} nodes, {{ include "celastro.fullname" . }}-0 to
{{ include "celastro.fullname" . }}-{{ sub (int .Values.replicas) 1 }}, each with its own volume,
attaching each other on port {{ .Values.wire.port }} as they come up. A collection
created WITH (splits = [...]) at any of them is spread one shard per pod.
{{- else }}
celastro is starting as one pod, {{ include "celastro.fullname" . }}-0, with its
data on the volume data-{{ include "celastro.fullname" . }}-0.
{{- end }}

{{- if .Values.console.expose }}

The console is exposed: every pod serves it on port {{ .Values.port }} behind
the Service {{ include "celastro.fullname" . }}-console ({{ .Values.console.service.type }}),
which spreads requests over the pods, and every pod answers the one token in
the Secret {{ include "celastro.consoleSecretName" . }}:

  kubectl -n {{ .Release.Namespace }} get secret {{ include "celastro.consoleSecretName" . }} -o jsonpath='{.data.CELASTRO_TOKEN}' | base64 -d

Send it as the X-Celastro-Token header (or ?t=) with every request, for
example from a pod in the cluster:

  {{ if .Values.tls.enabled }}https{{ else }}http{{ end }}://{{ include "celastro.fullname" . }}-console:{{ .Values.port }}/api/health
{{- if .Values.tls.enabled }}

The console and the wire are over TLS; the CA to verify against is `ca.crt`
in the Secret {{ include "celastro.tlsSecretName" . }}:

  kubectl -n {{ .Release.Namespace }} get secret {{ include "celastro.tlsSecretName" . }} -o jsonpath='{.data.ca\.crt}' | base64 -d > ca.crt
{{- else }}

This is plain HTTP and the token is the only thing protecting the database:
keep the Service inside a network you trust, put an ingress that terminates
TLS in front of it, or set tls.enabled.
{{- end }}
{{- else }}

The console binds 127.0.0.1 inside the pod and prints its URL, token included,
on stdout as it starts. Read the URL from the log and forward the port:

  kubectl -n {{ .Release.Namespace }} logs {{ include "celastro.fullname" . }}-0 | grep '^http'
  kubectl -n {{ .Release.Namespace }} port-forward {{ include "celastro.fullname" . }}-0 {{ .Values.port }}:{{ .Values.port }}

then open that URL. The token is the only thing protecting the database;
treat the URL as a password. A new token is printed at every start.
{{- end }}

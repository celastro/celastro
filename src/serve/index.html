History

    History is kept in this tab only, never on disk — statements can contain keys, tenant ids and other literals worth not leaving behind.

    The access token never sits in the address bar: the link the CLI printed was exchanged for a session on the first request and redirected away, and the token rides in a header from this page's own source. A reload keeps the session; a new browser needs the link, or the token typed into the sign-in page.
